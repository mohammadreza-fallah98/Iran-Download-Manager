# Iran Download Manager

## معرفی

نرم‌افزار مدیریت دانلود ایرانی — جایگزین بومی برای IDM — با رابط کاربری شبیه‌سازی‌شده و پشتیبانی از دانلود چندتکه‌ای، صف، زمان‌بندی و اکستنشن مرورگر.

## نقش‌ها

| نقش | توضیح |
|---|---|
| کاربر | هر شخصی که نرم‌افزار را روی ویندوز نصب کرده |

## قابلیت‌های اصلی

| قابلیت | توضیح |
|---|---|
| دانلود چندتکه‌ای | تا ۳۲ اتصال موازی برای یک فایل |
| صف دانلود | مدیریت اولویت و اجرای خودکار |
| زمان‌بندی | شروع/توقف خودکار در ساعت مشخص |
| گرب‌ر | استخراج لینک‌های فایل از یک صفحه وب |
| اکستنشن مرورگر | Chrome (Manifest V3) و Firefox (Manifest V2) برای ارسال لینک |
| تم دارک/لایت | شبیه IDM اصلی با آیکون‌های neon |
| کلیپ‌بورد | شناسایی خودکار لینک دانلود |
| دانلود ویدیو از مرورگر | دکمه‌ی «Download this video» روی ویدیو؛ فایل مستقیم، HLS (m3u8، حتی رمزشده با AES-128) و DASH (ویدیو + صدا ادغام‌شده) |
| صف‌های چندگانه | چند صف نام‌دار، انتقال دانلود بین صف‌ها، شروع/توقف هر صف جدا |
| محدودیت‌ها | سقف سرعت هر دانلود، سقف سرعت کل، سهمیه‌ی «X مگابایت در هر Y ساعت» |
| پس از اتمام دانلودها | بستن برنامه، خاموش‌کردن، ری‌استارت، Sleep یا Hibernate (با شمارش معکوس و امکان لغو) |
| منوی راست‌کلیک | Open with، Move/Rename (Ctrl+M)، Redownload، Refresh address، انتقال به صف، Copy URL، Properties |
| تنظیمات شبکه | پروکسی (ویندوز، اسکریپت PAC، دستی با HTTP یا SOCKS5)، User-Agent، تعداد اتصال ویژه‌ی هر سرور، ورود به سایت‌های رمزدار (رمزنگاری‌شده با حساب ویندوز) |
| تنظیمات دانلود | نوع فایل‌های خودکار و سایت‌های مستثنا، رفتار لینک تکراری، پوشه‌ی موقت، تاریخ فایل از سرور، اجرای آنتی‌ویروس روی فایل تمام‌شده، صداها |
| دانلود FTP | دانلود از آدرس‌های `ftp://` با ورود ناشناس یا نام کاربری و رمز، و ادامه‌ی دانلود |
| زبان فارسی | رابط کاربری قابل‌تعویض بین انگلیسی و فارسی (تنظیمات › عمومی › زبان)؛ پیام‌های پویا و چیدمان آینه‌ای فعلاً فارسی نیستند |
| آنتی‌ویروس و به‌روزرسانی | بررسی فایل‌های تمام‌شده با برنامه‌ی دلخواه، پرسیدن صف بعد از «دانلود بعداً»، قطع اینترنت بعد از اتمام، بررسی نسخه‌ی جدید |
| لیست دانلودها | خروجی گرفتن و وارد کردن لیست، افزودن گروهی آدرس‌ها از کلیپ‌بورد، نمایش مجموع حجم |

## دسته‌بندی فایل‌ها

Compressed · Documents · Music · Programs · Video · General

## کلاینت‌ها

- اپلیکیشن ویندوز (Rust + egui)
- اکستنشن Chrome
- اکستنشن Firefox

## واژه‌نامه

| واژه | معنا |
|---|---|
| Part | یک بازه بایتی از فایل که یک اتصال دانلود می‌کند |
| Handle | مرجع مشترک بین thread‌های دانلود و UI |
| Probe | بررسی اولیه URL برای سایز و قابلیت resume |
| HLS / DASH | روش‌های پخش ویدیوی قطعه‌قطعه؛ برنامه قطعه‌ها را می‌گیرد و به یک فایل تبدیل می‌کند |
